FACEFORGE BDO 0.5.1
===================

RUN THE APP
-----------
Double-click:
  FaceForge BDO 0.5.1 - STANDALONE.exe

The EXE opens a dedicated FaceForge BDO desktop window.
It does not open your normal browser. Close the window or use Settings > Exit FaceForge BDO when finished.

NORMAL WORKFLOW
---------------
1. Create Face
   - Choose the target face image.
   - Load a starting BDO preset.
   - Click Create Face Preset.
   - Save directly to BDO or download the generated preset.

2. Build your reference library once
   - Open Preset Library.
   - Scan the BDO customization folder.
   - For presets you may want FaceForge to learn from, click Add Screenshot.
   - Attach one clean in-game screenshot of that preset.

3. Adjust if needed
   - Open Adjust Result on the generated result card.
   - Supported facial groups are already prefilled.
   - Unsupported groups stay at 0% unless you change them.

MORE TOOLS
----------
Merge Presets, Preset Laboratory, and Calibration are under More Tools.
They are optional and no longer block the normal Create Face workflow.

BACKUPS
-------
Overwriting an existing preset creates a timestamped backup under:
  .FaceForge BDO Backups

BUILD FROM SOURCE
-----------------
This clean source pack intentionally contains no old repair, retry, push, or publishing BAT files.

Requirements:
  Go 1.22+
  Node.js 20+
  PowerShell

Run:
  .\build.ps1

Or create the full local package with:
  .\package.ps1
