FACEFORGE BDO 0.3.0
===================

RUN THE APP
-----------
Double-click:
  FaceForge BDO 0.3.0 - STANDALONE.exe

The EXE opens a dedicated FaceForge BDO desktop window.
It does not open your normal browser. Close the window or use Settings > Exit FaceForge BDO when finished.

NORMAL WORKFLOWS
----------------
1. Face from Photo
   - Choose the target face image.
   - Load a starting BDO preset.
   - Optionally add a helper preset and screenshots for automatic suggestions.
   - Continue to Merge Presets to generate and save the final file.

2. Merge Presets
   - Load the Starting preset.
   - Load the Preset to borrow from.
   - Pick a quick mix or adjust individual feature weights.
   - Create, download, or save the merged preset.

3. Preset Library
   - Scan the BDO customization folder.
   - Send files directly into either normal workflow.

ADVANCED TOOLS
--------------
Preset Laboratory and Calibration are under Advanced Tools.
They are optional reverse-engineering utilities and are not required for normal merging.

BACKUPS
-------
Overwriting an existing preset creates a timestamped backup under:
  .FaceForge BDO Backups

BUILD OR PUBLISH
----------------
- BUILD_EXE.bat performs a local build and requires Go 1.22+ and Node.js 20+.
- PUSH_TO_GITHUB.bat creates or updates the repository.
- When release creation is selected, GitHub Actions builds the EXE on a Windows runner.
  Go and Node.js do not need to be installed locally just to publish the release.
