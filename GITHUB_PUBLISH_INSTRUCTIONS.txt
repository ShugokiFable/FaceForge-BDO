FACEFORGE BDO 0.4.0 - GITHUB PUBLISH
=====================================

1. Extract FaceForge BDO 0.4.0 - GITHUB READY.zip.
2. Open the extracted FaceForge BDO 0.4.0 - SOURCE folder.
3. Double-click PUSH_0.4.0_TO_GITHUB.bat.
4. Press Enter at the confirmation prompt.

Requirements:
- Git for Windows
- GitHub CLI authenticated as ShugokiFable

Authenticate once with:
  gh auth login

The publisher:
- clones or creates ShugokiFable/FaceForge-BDO,
- overlays and commits the complete 0.4.0 source,
- pushes main,
- replaces tag and release v0.4.0,
- uploads the already-built standalone EXE, source ZIP, release ZIP,
  and SHA-256 manifest directly.

Go and Node.js are not required for this publishing BAT.
